# 前端与 Agent 交互

## 适配与架构

新 Web 产品默认 Next.js App Router、React、TypeScript strict、Tailwind CSS、语义 CSS 变量与统一图标。稳定版本及锁文件以实际核对为准。沿用已有可维护框架/组件；复杂可访问交互才引入 Radix/shadcn，缓存失效复杂才加 TanStack Query，跨层临时状态复杂才加 Zustand，复杂动态表单才加 React Hook Form/Zod。

路由组织页面，业务 feature 组织组件/Hook/schema，API、流式、鉴权和媒体放集中适配层。UI 不拼供应商接口；服务端组件负责合适的首屏/静态展示，浏览器交互放必要的客户端边界，避免整站客户端化。

| 四类状态 | 来源与存放 |
| --- | --- |
| 可分享查看位置 | URL 中任务 ID、筛选、页签；不放秘密和大对象 |
| 业务事实 | 后端任务、产物、权限；客户端缓存不是最终事实 |
| 未提交临时交互 | 组件 State/局部 Context；表单失败保留输入 |
| 非关键偏好 | Local Storage 或用户配置，如主题、侧栏 |

刷新按任务 ID 重新取状态；乐观更新有失败回退。Local Storage 不冒充最终业务结果。浏览器专属数据在客户端读取，首次渲染保持稳定，避免 hydration 不一致。

## 任务与页面状态矩阵

设计实际需要的状态，不强迫后端实现全部展示枚举：

| 含义 | 用户表现 | 实现要求 |
| --- | --- | --- |
| idle / submitting | 可输入 / 正在提交 | 防重复，区分停止等待与取消任务 |
| queued / running / streaming | 已受理 / 执行中 / 增量输出 | 无真实百分比就显示阶段，不伪造进度 |
| waiting_user | 等待采用、编辑或补充 | 展示已有结果、选项影响与下一步，保存确认状态 |
| succeeded / partially_succeeded | 完成 / 部分成功 | 区分最终、中间产物、失败项和可重试范围 |
| failed / cancelled | 失败 / 已取消 | 给恢复办法；后端确认取消才显示已取消 |
| disconnected / stale | 断线 / 状态待刷新 | 客户端观察状态，不修改后端生命周期 |
| 未知后端状态 | 暂不可确认 | 安全兜底、记录并重查，不映射成成功 |

页面数据还要区分 loading、empty、permission_denied、not_found、failed；请求未结束不提前显示空数据。状态文案回答“发生什么、需要做什么、下一步是什么”。

## 通信与任务控制

- 单向流用 SSE/Fetch Streaming；POST、请求体或自定义鉴权头选支持它们的实现。双向高频才评估 WebSocket，短请求用普通 HTTP。
- 普通 API 与流式 API 共用地址/身份策略。检查真实代理是否缓存流、超时或丢鉴权；关闭旧连接，任务切换后不把旧事件写入新任务。
- 重连先按 ID 查询，再恢复流或轮询；基于事件 ID/偏移去重，不重新创建昂贵任务来恢复。
- 轮询有间隔、退避、页面可见性策略，终态停止；同任务避免组件各自轮询。
- 批量渲染文本，用户在底部才跟随滚动。辅助技术不逐 Token 播报。只展示允许公开的阶段摘要，不泄露隐藏推理、私密 Prompt 和原始日志。
- 按钮防重复配合后端幂等；提交超时先查是否已创建。重试说明复用产物范围与追加费用。
- AbortController 只停止浏览器请求；取消任务需真实后端能力。取消结果未知先查状态；后端不能取消时写“停止等待”。

## 契约、输入与产物

统一 API 客户端处理 base URL、鉴权、超时、错误，外加业务适配。稳定 OpenAPI 可生成类型，但重要外部数据仍需运行时校验，不用 any 消除错误。

错误内部可统一 code、userMessage、retryable、requestId、fieldErrors，用户只看可理解信息。表单就近校验、失败保留输入，未冻结规则标临时。默认模型在可选项内，保存的模型不可用就提示，不偷偷切换。

产物按业务定义 ID、kind、status、名称、受控 URL/对象引用、MIME、大小、时间、元信息，统一文本/图像/视频/音频/文件/JSON 的预览下载和失败。预留媒体尺寸，处理 URL 过期、权限与跨域，Object URL 用完释放；私有资产不使用永久公开链接绕过隔离。

上传前说明限制和进度，后端复核真实类型、安全文件名与归属。模型 Markdown/HTML 视为不可信，限制危险标签和链接；权限必须在后端验证。

## 视觉、响应式与可访问性

优先已确认设计系统/设计稿，其次 PRD 品牌和参考；缺省先给中性方向并做代表页。说明颜色、字体、密度、圆角、结构，根据反馈再扩展。参考网站能访问就读取，只复用许可允许的资产；中文配置系统字体 fallback，不打包不明授权商业字体。

语义变量统一背景、文字、品牌、边框、状态、字号/行高、间距、圆角/阴影与 hover/focus/disabled/loading/error。先复用，再抽取真实重复模式，不提前制造万能组件。

无另行要求时以 390、768、1280、1440 CSS px 为 Web 布局样本；桌面限定应用按目标终端适配。检查核心每页和弹窗：抽屉关闭不残留遮罩，弹窗可滚动，媒体不撑屏，键盘弹出后操作可达，表格受控滚动。触控目标约 44×44px 为设计建议。

使用语义 HTML、关联 label、键盘操作、可见焦点、弹窗焦点返回、非纯颜色状态、适度 live region，尊重减少动画设置。图标按钮有可访问名称，按钮说明业务动作。测量后决定懒加载、分页/虚拟化和优化，不用以后优化掩盖明显卡顿或泄漏。

Cookie 按场景配置 HttpOnly/Secure/SameSite 并处理 CSRF，不默认长期 token 存 Local Storage。NEXT_PUBLIC_ 仅放公开配置。监控/埋点按需接入，不上传完整隐私输入，失败不阻塞业务。

## 交付

按“适配与契约 → 代表页 → 第一条真实闭环 → 确认/重试/恢复 → 发布质量”拆分，可合并。补齐原阶段文档的状态矩阵与接口，不另建重复体系。

执行 lint、类型检查、相关单元/组件/集成检查及生产构建；真实启动检查 Console、Network、状态、尺寸、媒体和断网/刷新恢复。走通“输入 → 真任务 → 确认（如有）→ 真产物 → 刷新可恢复”。构建、按钮可点和 mock 展示均不代替联调。证据见 [验收与交接](verification.md)。
