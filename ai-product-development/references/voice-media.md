# 语音与实时媒体

仅在产品需要时读取。区分上传音频、回合制语音、全双工对话。MVP 未指定全双工时，可推荐“录音 → 发送 → ASR → Agent → TTS → 播放”；不自行削减已指定的打断、延迟或原生能力。

## 录音与播放

- 线上使用 HTTPS 或浏览器认可的安全上下文。获麦克风授权才录音，拒绝、无设备、设备占用有反馈。
- 运行时探测 MediaRecorder 的 MIME/codec，不硬编码 Chrome/Safari 必然支持某格式。上传真实 MIME，后端验证/转码，以目标浏览器实测为准。
- 离开时释放轨道、录音器、监听和临时 URL；失败保留可恢复录音或说明丢失边界，防重复发送。
- 若推送 PCM/base64 分片，先约定采样率、声道、采样格式、序号和终止/错误事件，不能当完整音频直接播放。按时间轴排队并处理缓冲，允许文字和音频独立到达。
- 处理用户手势/自动播放限制，必要时恢复 AudioContext；会话切换、真实打断、取消时停播清队列。全双工另定回声处理、轮次边界与迟到片段规则。
- 回放选受保护同源资源、短期签名地址，或带鉴权 fetch → Blob → Object URL；保持原权限契约，不把长期 token 放 URL。对象 URL 在结束或卸载后释放。

## 验证

实际桌面浏览器与目标手机走录音 → 上传/转写 → 回复 → 播报 → 回放。交付目标含 iPhone 必须实机验证；桌面模拟尺寸不能证明编码、麦克风和自动播放兼容，缺设备列待验证。

覆盖拒绝权限、重复发送、断网、离开、会话切换、音频错误和历史轮次恢复。评分/答案是否会中展示由 PRD 决定，不把某个语音对练示例推广为通用禁令。
